# 1. Used libraries, tools, etc.
1) **GNU** - A huge thank you to **GNU** for their wonderful tools. For a long time, I hopped around between different toolkits, used various C compilers, and tried out different assemblers, but none of them ever felt quite right - and over time, I noticed that I had started using only **GNU** tools for working with C and assembly, and these tools have become second nature to me.
2) [lordmilko](https://github.com/lordmilko) - Thank you for providing the cross-development toolkit in [your repository](https://github.com/lordmilko/i686-elf-tools). I use these tools for GitHub Actions.
3) [Fabian Hemmer (copy)](https://github.com/copy) - Thanks for the really cool emulator, [v86](https://github.com/copy/v86).  Thanks to it, I was able to create a [page on GitHub Pages](https://childofsorrow08.github.io/The-Wired/) where you can test the kernel right in your browser without downloading anything!
